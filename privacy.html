AETHER Privacy Policy

Last updated: 15 November 2026 · Prototype version 1.2.1

Summary

AETHER has no user accounts, analytics or advertising. Health entries are stored in this browser on this device. The prototype does not provide a health-record server or synchronize records to a server.

Data stored locally

  • Health check-ins: values and notes that you enter, stored in browser local storage.
  • Demo and app state: selected crew/environment, local acknowledgements, tasks, audit events and cached NASA feed metadata.
  • Settings: any NASA API key or optional AI-provider endpoint, model and API key you choose to save. These are stored in browser local storage and are not encrypted by this prototype. Do not save secrets on a shared or untrusted device.
  • Exports: JSON, CSV and print/PDF outputs are generated on your device. You control where exported files are sent or stored.

Network use

When online, AETHER may request public data from NASA DONKI (api.nasa.gov), NASA Technical Reports Server (ntrs.nasa.gov), NASA Image and Video Library (images-api.nasa.gov), and the host serving the project's optional feed-snapshot.json and knowledge.json. These requests are for public space-weather, research, media or project data and do not include crew health records. NASA's own privacy terms apply to NASA services.

Optional external AI assistant

The assistant works from its built-in local knowledge base by default. If you configure and enable an external language-model provider, AETHER sends your prompt, recent chat messages and retrieved knowledge-base context to that provider. Current crew readings are sent only if you separately enable the share-readings checkbox. The provider's privacy policy applies to that traffic. Use a trusted provider or secure proxy, and do not enter sensitive personal or medical information. Turn the provider off to stop these external AI requests.

Retention and deletion

Locally stored data remains in this browser until you use Settings & Privacy → Delete all local data or clear this site's browser storage. Exported files are not deleted when app data is cleared. Browser and operating-system backup behavior is outside AETHER's control.

Important limitations

AETHER is a demonstration prototype, not a medical device. It uses synthetic crew and cabin data, generic illustrative thresholds and public NASA context feeds. It has not been clinically validated and is not approved or endorsed by NASA or any space agency.

Contact

This challenge prototype does not currently provide a public support contact.
